Security & Engineering Spec

Cryptographic Architecture

A transparent, modular stack built on open protocols and native system firewalls.

WireGuard Kernel Protocol

Uses ChaCha20-Poly1305 authenticated encryption and Curve25519 ECDH key exchange. Minimal cryptographic surface area ensures near line-speed throughput and reduced battery draw.

OpenVPN 256-bit AES Tunneling

Full compatibility with Tsukuba University academic relays. Supports dynamic TCP/UDP handshakes to penetrate restrictive carrier-grade NATs and censorship blocks.

Geospatial Gateway Visualization

Interactive world map rendering node distribution across North America, Europe, and Asia-Pacific. Features instant latency benchmarking and round-trip time sorting.

Platform-Native Kill Switch

Interacts directly with kernel packet filtering engines (nftables/iptables on Linux, WFP on Windows, and pf on macOS) to prevent IPv4, IPv6, and DNS packet leakage.

Decentralized Mirror Failover

Automatically polls and reconciles active relay servers from multiple verified HTTP/HTTPS mirrors with local SQLite/JSON fallback caching during network interruptions.

Daemon & IPC Supervisor

Background process management with privilege separation. Allows unprivileged GUI and CLI commands to trigger secure tunnel activation over local IPC sockets.

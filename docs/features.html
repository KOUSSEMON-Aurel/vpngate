Technical Overview

High-Speed Privacy by Design.
State-of-the-Art Architecture.

A transparent, decoupled architecture built with modern Kotlin, Jetpack Compose, and native cryptographic tunnels.

⚡

WireGuard Kernel Protocol

Utilizes ChaCha20-Poly1305 authenticated encryption and Curve25519 key exchange. Lightweight codebase reduces battery drain and CPU overhead on Android.

🔐

OpenVPN 256-bit AES

Full compatibility with academic VPN Gate relay servers with robust TCP/UDP fallback to pierce restrictive firewalls and censorship barriers.

🗺️

Interactive Gateway Map

Real-time geospatial visualization of active worldwide relay nodes. Instant latency sorting, ping filtering, and connection telemetry.

📱

Adaptive Android 15 Ready

Native support for Edge-to-Edge display, Material You dynamic color, adaptive launcher icons, and system dark/light theme switching.

🛡️

Kill Switch & DNS Shield

Built-in protections against IPv6 leaks and unencrypted DNS requests to ensure zero accidental traffic exposure.

🌍

Multi-Language Native Support

Instant on-the-fly switching between English, French, Spanish, German, and Japanese directly within the mobile application.

## vpngate warp

Connect to Cloudflare WARP (wgcf + wg-quick, or warp-cli)

### Synopsis

Connect to Cloudflare WARP. Uses wgcf to register an account, generate a
WireGuard profile and bring it up with wg-quick when both are installed;
otherwise falls back to the official warp-cli daemon. The wgcf path needs
root (it creates a tun interface).

```
vpngate warp [flags]
```

### Options

```
  -h, --help                 help for warp
      --wgcf-config string   path to an existing wgcf WireGuard profile (default: <config>/wgcf/wgcf-profile.conf)
```

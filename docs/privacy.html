Privacy Policy for OpenRelay VPN

Effective Date: September 2026 • Version 1.0

OpenRelay VPN ("we", "our", or "the application") is committed to respecting and safeguarding user privacy. This Privacy Policy outlines our principles, technical safeguards, and data handling practices in compliance with Google Play Developer Policies and global privacy regulations.

1. Strict Zero Personal Data Collection

OpenRelay VPN does NOT collect, store, track, sell, or transmit any personally identifiable information (PII):

  • No User Accounts: No sign-up, registration, email address, password, or profile information is ever required or collected.
  • No Financial or Billing Data: The application is 100% free and open-source; no payment details or billing identifiers are processed.
  • No Trackers or Analytics: The application contains zero third-party advertising SDKs, behavioural trackers, or analytics telemetry services.

2. Use of Android VpnService

OpenRelay VPN utilizes the official Android VpnService API to establish secure virtual private network tunnels (via OpenVPN and WireGuard protocols):

  • Cryptographic Encryption: All Internet traffic transmitted while the VPN tunnel is active is encrypted to safeguard user communications from eavesdropping on untrusted networks (e.g. public Wi-Fi).
  • No Client-Side Logging: The application itself never inspects, captures, logs, or stores your browsing history, visited URLs, web traffic payloads, or DNS queries.

3. Public Relay Server Mesh

OpenRelay VPN connects users to an open network of public volunteer-operated relay servers and high-speed public Anycast gateways. OpenRelay VPN is an independent client software. Volunteer server operators maintain operational independence according to their own server configurations. Users can inspect server details, uptime, and protocols directly in the application before connecting.

4. Local On-Device Preferences

All user preferences (such as Dark/Light theme mode, selected UI language, protocol choice, and acknowledgement of the prominent disclosure dialog) are stored strictly on your local device using Android SharedPreferences. These settings never leave your device.

5. Open Source Transparency & License

OpenRelay VPN is free and open-source software distributed under the GNU General Public License (GPL). The complete source code is transparently available for community inspection and audit at: github.com/KOUSSEMON-Aurel/vpngate.

6. Contact & Support

If you have any questions or feedback regarding this Privacy Policy, please open an issue on our official GitHub repository.
